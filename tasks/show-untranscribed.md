# "Show me" untranscribed pages

Add a "Show me" button to the export dialog's "Not transcribed yet" message. It closes the dialog and highlights those pages' thumbnails. Transcribe All exists, but this is also how you find pages whose transcription failed.

The selected page already has a bold frame in the selection colour; make this highlight distinct from it (e.g. a `warn_fg_color` badge) so both show on one thumbnail.
