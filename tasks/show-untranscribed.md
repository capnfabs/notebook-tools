# "Show me" untranscribed pages

Add a "Show me" button to the export dialog's "Not transcribed yet" message. It closes the dialog and highlights those pages' thumbnails. Keep it, even when Transcribe all is supported: it's also how you find pages whose transcription failed.

While we're here: add an outline for the currently selected page. If the currently selected page is also not transcribed, both indicators should be shown.
