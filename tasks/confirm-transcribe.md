# Confirm before transcribing

Transcription is expensive. Selecting another page while on Transcribed shouldn't start it automatically; show a Transcribe button instead. Cached pages (`transcription-cache.md`) show straight away. Switching to the 'transcribed' view from a different one _also_ automatically starts transcription. Supersedes the auto-start in `decisions/2026-10-23-transcribe-on-toggle.md`.
