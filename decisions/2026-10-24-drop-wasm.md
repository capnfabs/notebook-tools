# Drop the WASM build

The app is native-only. The web build cost target cfgs, split dependency tables, an async file-read path, a single-threaded fallback and extra CI steps, and it couldn't transcribe or export anyway. Rayon, reqwest, rfd and the cache are now plain dependencies, and Trunk is gone. This supersedes `superseded/2026-10-23-rayon-native-only.md` and `superseded/2026-10-23-trunk-for-wasm.md`. WASM rationale in older entries is history.

Reason: Human Taste.
