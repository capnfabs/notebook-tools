# Projects: pages, corners and transcripts saved to `.notebook` files

File ▸ New Project (⌘N), Open Project… (⌘O), Save (⌘S) and Save As… (⇧⌘S) save the pages, in order, with their corners and transcripts, to one gzipped JSON file (see `decisions/2026-10-31-gzip-projects.md`; `notebook_core::project`, `PROJECT_VERSION`, format snapshotted by a test). Photos aren't copied in: each page names its file by a path relative to the project (absolute if they share only the root), its SHA-256 and size. Transcripts are saved whole, corrections and Claude's raw answer included, so a project doesn't need the cache and survives a schema change; the answer lets a style change re-read it (`Transcript::restyled`, now used for all restyling rather than re-reading the cache). One project is open at a time, and the app always starts untitled; no view, selection, export target or settings are saved. The cache still works as before for unsaved work. A photo that's gone or changed when a project opens leaves its page in place without it, saved again as it was: see `2026-11-15-missing-pages-shown.md` (finding moved photos and EXIF IDs: `tasks/relink-photos.md`).

Unsaved changes are found by comparing the pages with what was last saved or opened, every frame, rather than by noting each change: none can be missed, and undoing a change undoes "Edited". Anything saved counts, a transcript arriving too; restyling on open doesn't. The title says "— Edited". New, Open, closing the window and Quit ask Save / Don't Save / Cancel (Save on an untitled project asks where, and cancelling that cancels the lot); ⌘⌫ is Don't Save. A new project gets fresh transcription and loading queues, so jobs still running for the old one go uncollected. Quit is the app's own command, since AppKit's ends the app without telling it; Dock ▸ Quit, logout and shutdown send `terminate:`, which winit lets through, so `applicationShouldTerminate:` is added to winit's delegate at runtime (`crates/app/src/quit.rs`) to cancel while there are unsaved changes and ask instead. Reason: Human Taste (projects at all, the menu, self-contained transcripts, starting untitled, saving nothing else, what counts as a change, the prompt, the full quit fix); unquestioned agent recommendation for the format, change-by-comparison and fresh queues.

Projects also open by drop and from the command line: see `decisions/2026-10-31-open-by-drop-and-argument.md`.
