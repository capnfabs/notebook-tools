# Page order

Pages start in filename order and can be rearranged by dragging thumbnails or with ⇧⌘←/→ (since `2026-10-31-arrow-keys-move-focus.md`); "Sort by name" puts them back, leaving pages with the same name in their order (`2026-11-15-page-ids.md`). While the pages are still in filename order, new drops merge in by name; once rearranged, they go at the end, sorted by name within each drop. The order is whatever's on screen, so there's no hidden "manual" flag: moving pages back into filename order resumes merging.

The selected page gets a 3pt frame in the theme's selection colour, its name and position in the toolbar, and the strip scrolls to keep it in view.

Reason: unquestioned agent recommendation (where new drops go, the frame); Human Taste (the button, keyboard moves, toolbar name, scrolling).
