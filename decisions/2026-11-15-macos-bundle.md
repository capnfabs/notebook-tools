# The macOS app bundle

`scripts/bundle-macos.sh` builds `Notebook Tools.app` and a plain DMG (the app and an /Applications link) with Apple's own tools: `cargo build --release`, the committed `crates/app/macos/Info.plist` with both versions set to the Cargo version, the Icon Composer `AppIcon.icon` compiled by Xcode's `actool` into `Assets.car` plus an `.icns` for older macOS, and `codesign`. A plain `.icns` was tried first: macOS 26+ shrinks any that isn't exactly its squircle onto a grey plate, so the system masks a layered icon itself instead. eframe is given an empty window icon, or it swaps the Dock icon for egui's at launch. Builds are arm64 only, macOS 11+, and signed ad hoc, or with `--identity` using a local self-signed certificate so the keychain keeps trusting rebuilds. Developer ID signing and notarization wait for an Apple Developer membership (`tasks/macos-developer-id.md`). The display name is "Notebook Tools"; the binary, the bundle id (`net.ftamp.notebook-tools`, the keychain service), and the cache and settings directories keep `notebook-tools`. `.notebook` files are ours (`Owner`, exported UTI `net.ftamp.notebook-tools.project`, conforming only to `public.data` so archive tools don't claim it). JPEG, PNG and HEIC/HEIF are `Alternate`: listed under Open With and accepted on the Dock icon, but never their default app. `check.sh` doesn't build the bundle; `crates/app/tests/bundle_plist.rs` checks the plist against the code.

winit doesn't take the files Finder opens, so `crates/app/src/finder_open.rs` adds `application:openURLs:` to winit's application delegate on `NSApplicationWillFinishLaunchingNotification`. That's late enough that the delegate exists, and early enough for the files that launch the app, which arrive before eframe builds it. Checked 2026-11-15 with `open -a` on a cold launch and on a running app. Each batch of files is handled as a drop on the window, under the same rules (`2026-10-31-open-by-drop-and-argument.md`). An old-style `-psn_…` argument is ignored. Logs from a Finder launch go nowhere for now (`tasks/finder-logs.md`). Reason: Human Taste (arm64, the name, ad hoc plus a self-signed identity until Developer ID, Open With only for photos, opening as a drop, a plain DMG, our own script, versions from Cargo, not in `check.sh`); unquestioned agent recommendation for the rest.
