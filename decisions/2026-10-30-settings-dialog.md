# Settings dialog: model and markdown style, saved as JSON

Settings… (⌘,, in the app menu) holds the transcription model, with what each is good for, and `MarkdownStyle` (the underline mark and the heading level of a wholly underlined line). The toolbar's model dropdown is gone. The dialog edits a copy: Save applies it, Cancel or Escape drops it, as other dialogs do. Settings are saved as JSON in the OS config directory (`dirs::config_dir()/notebook-tools/settings.json`: `~/Library/Application Support` on macOS, `~/.config` on Linux, `%APPDATA%` on Windows), with defaults for anything missing or unreadable. egui's bundled fonts have no ℹ glyph, so the info icon is painted.

A new style reaches transcripts parsed from then on and, re-read from Claude's answer that each keeps (`2026-10-31-projects.md`), the loaded ones the user hasn't corrected; corrected ones keep their text until Reset Transcript, which also restyles. Each `Transcript` records the style it was parsed in, so stale ones are found by comparing. A note beside the style says so. Reason: Human Taste (JSON file, model only in Settings, Cancel/Save, the note and its wording); unquestioned agent recommendation for the rest.
