# Export with missing pages: Markdown from the saved transcript, PDF needs the photos

Markdown (file or clipboard) needs only each page's saved transcript, used as it is: a page whose photo is missing exports like any other, in its place, and Markdown doesn't wait for pages still loading. A PDF needs every page's photo, loaded. Each page that blocks export is named once. For a PDF: "Need to relink these photos for export" (missing, transcribed), "Need to relink and transcribe these photos for export" (missing, untranscribed), "Not transcribed yet" or "Still loading". For Markdown, only "Not transcribed yet", whether or not the photo is missing.

Reason: Human Taste.
