# `ant`'s login as the last source of credentials

Credentials come from `ANTHROPIC_API_KEY`/`ANTHROPIC_AUTH_TOKEN`, else a key saved in the keychain, else `ant auth print-credentials`. Only the first found is used; if it fails, nothing else is tried, so a broken key never quietly bills another account. `ant` is found on `PATH`, then `/opt/homebrew/bin`, `/usr/local/bin` and `~/.local/bin` (apps opened from Finder don't get the shell's `PATH`). It's asked on a thread at launch, while the window opens (waiting up to 3s), and counts only if logged in; otherwise transcribing asks for a key as before. Its token is kept until 5 minutes before `expires_at`, behind a lock so pages sent together ask once, and dropped on a 401 so the next page asks `ant` again (no retry). The refresh token in its output is never kept. Settings shows the account's email and org. Any `ANTHROPIC_BASE_URL` it gives is ignored.

`--offline` gets promoted to an app flag and disables transcription entirely by removing credentials. Debug builds also take `--no-keychain`, which `scripts/run.sh` passes so dev runs use the environment or `ant` without keychain prompts; it no longer injects a token, and `scripts/with-claude-token.sh` stays for the live core tests. Reason: Human Taste (priority, first source only, caching until expiry, detection at launch, showing the account, `--offline` in the app, `--no-keychain` for dev); unquestioned agent recommendation for the rest.
