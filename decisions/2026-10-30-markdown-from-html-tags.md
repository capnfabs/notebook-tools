# Markdown: Claude writes HTML tags, converted locally

The prompt asks for `<u>…</u>` for underlines (Opus already wrote them unasked; Sonnet mostly dropped them), `<sup>…</sup>` for superscripts and `---` for a line of only a dash. Parsing converts the underlines through `MarkdownStyle` (`crates/core/src/markdown_style.rs`): a line underlined as a whole becomes a `##` heading, other underlines `_x_`. Dash-only lines (`—`, `–`, `-`) become `---`. Superscripts are kept as HTML, with no conversion: cached Pandoc-style `^th^` stays until the page is transcribed again. Conversion runs on every parse, so cached transcripts follow it without bumping `CACHE_VERSION`. The user picks `MarkdownStyle` in Settings (`2026-10-30-settings-dialog.md`). Alternatives that repeat the uncertain word (35 of 69 in the cache) are dropped when parsing, rather than asking Claude not to write them, which risked it flagging fewer words. An uncertain word left with no alternatives still needs a look. Spread reading order was left alone: all 13 cached spreads were read left page then right.

Reason: Human Taste (tags converted locally so the style is configurable, `##`, `<sup>`, no superscript conversion, keep cached transcripts); unquestioned agent recommendation for filtering alternatives locally.
